# Contributing to PhishGuard

Thank you for your interest in contributing to the Mobile Phishing Awareness & Training Kit! As an open-source educational platform, we welcome collaboration to expand scenario libraries and detection heuristics.

## Contribution Workflow

1. **Fork the Repository:** Create a personal clone of the repository to test your variations locally.
2. **Implement Structural Changes:** Tidy up logic parameters, add threat variations, or optimize localized script patterns.
3. **Validate Interface Integrity:** Ensure your styling variations align correctly with standard smartphone layout thresholds.
4. **Submit a Pull Request:** Open a descriptive PR outlining your optimization additions clearly. 

## Code Quality Standards
- Ensure code updates maintain clean string layouts to prevent compilation breaking inside build chains.
- Document any heuristic additions cleanly within the main logic files.
