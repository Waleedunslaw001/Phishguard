PhishGuard: Mobile Phishing Awareness & Training Kit

PhishGuard is an interactive, client-side Progressive Web App (PWA) built to train non-technical users, learners, and employees on how to detect and defend against modern mobile social engineering threats like Smishing, Typosquatting, and Credential Harvesting.

## 🚀 Core Features
- **Interactive Quiz Lab:** Offers real-world mobile phishing message simulations with instant, context-driven educational feedback.
- **Heuristic Threat Inspector:** Employs an algorithmic matching engine (utilizing Levenshtein Distance) to evaluate URL domain proximity against protected brand names, flagging deceptive protocols and high-risk top-level domains (TLDs).
- **Dynamic Scenario Builder:** An administrative portal allowing educators to configure custom localized threat variations directly via the interface.
- **Offline Infrastructure:** Designed with standard Web Manifest patterns and Service Workers (`sw.js`) to function seamlessly in low-connectivity environments without central server overhead.
- **Audit Logging & Reporting:** Saves local state information using `localStorage` with features to export activity compliance as structured CSV data and generate automated printable completion certificates.

## 🛠️ Built With
- HTML5 / Vanilla JavaScript (ES6+)
- Tailwind CSS
- Web Storage API / Service Workers
